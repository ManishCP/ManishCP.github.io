# Manish CP — Portfolio

Live portfolio: https://manishcp.github.io/

The previous address, https://manishcp.github.io/manishportfolio/, redirects to the main site.

Static HTML, CSS, and JavaScript with GSAP animations. GitHub Pages publishes the root of `main`.

Run locally with `python3 -m http.server 4173` and open http://localhost:4173/.

The résumé is stored at `Docs/ManishCP_Resume.pdf`. Replace that file to update the download.
